## Overview

This Streamlit application serves as an interactive academic portfolio and personal autobiography built for the **CSIT349 Applied AI** laboratory activity. It presents an editorial, paper-inspired scrapbook aesthetic that organizes personal background, academic progression, technical self-assessments, and software engineering projects into a clean physical-notebook interface.

### Highlights
- **Editorial Paper Aesthetic:** Custom color palette (`#EAE5DA`, `#F8F6EF`, `#292820`), subtle washi tape, lined paper, and sticky note accents with zero emojis.
- **Autobiography:** Structured reflections across Background, Education, Interests, and Milestones.
- **Skills Matrix:** Self-assessment on a 1-to-5 scale across 16 technical competencies with interactive Altair charts and data tables.
- **Project Showcase:** Detailed portfolio sheets for 3 key works:
  1. *CIT-U OJT Internship Management System*
  2. *Modular Monolith Integration (Tiangge & LegacySupply)*
  3. *SimpleNotes Android Application*
- **Visitor Feedback:** Interactive feedback form storing session responses without external dependencies.
- **Exportable Dossier:** One-click download button generating a structured Markdown portfolio document.

## Getting Started

### Prerequisites
- Python 3.10+
- `pip`

### Installation
Clone this repository and install the dependencies:
```bash
git clone https://github.com/Pochyy/BasicStreamLitApp.git
cd BasicStreamLitApp
pip install -r requirements.txt
```

### Running the Application
```bash
streamlit run app.py
```
Open your browser at `http://localhost:8501`.
